# BLACKLINE: OVERWATCH 전환 계획

범위: 사용자 개발 지시서의 1단계. 이 문서는 전체 게임 구현 완료를 의미하지 않는다.

## 분석 기준

최종 기준 커밋 `c5704a8` (원격 main, v2026.11.10.02). 초기 로컬 `470e338`에서 시작했으나 원격 100개 추가 커밋을 확인한 뒤 최신 기준으로 재배치했다. 추가된 17개 파일의 633행 삽입/74행 삭제를 그대로 보존한다. 정적 HTML/JavaScript 프로젝트이며 빌드 도구나 서버 데이터베이스가 없다. 진입점 `index.html`은 약 62KB의 UI·초기 상태·저장 코드와 다수의 전역 스크립트를 실행한다. 최신 변경에는 의료후송 잔여 대기 정리, 지상 복귀와 헬기 도착 조건 분리, 복귀 정체 복구, 비동기 저장 보강, 60~96명 적 중대·지원전력·접촉 확률 변경과 UI 보정이 포함된다. 적 중대의 전체 아군 위치 참조와 기존 대규모 전력 정책은 OVERWATCH의 제한 정보·6명 출격 규칙과 맞지 않으므로 그대로 이식하지 않는다. 기존 상태는 `blackline_pmc_v1`, `blackline_pmc_v1_backup`에 저장한다. `save-codec.js`는 기존 JSON 및 BLZ1 압축 저장을 모두 읽는다. `save-scheduler.js`/`save-worker.js`는 기존 키에 직접 기록하므로 새 앱에서는 실행하지 않는다.

기존 2D 전장은 좌표·탄약·피해를 공유하지만 모든 정보가 통신 상태를 거쳐 표시되는 구조는 아니다. 기존 Three.js 장면에는 별도 배우 생성·위치가 있으므로 새 3D 완료로 보고하지 않는다. 다중 전역 래퍼/타이머, 이전의 중립군 관측 후 이동 교착, 군집 경로 충돌, 산악 후송 판정, 전체 화면 재생성 및 저장 비용이 주요 회귀 위험이다. 새 앱은 구형 타이머를 아예 실행하지 않는다.

## 새 경계

- `overwatch/core.js`: DOM 없는 상태 스키마·제약·유효성 검사. 최대 10명, 출격 2~6명, ALPHA/BRAVO/CHARLIE 각 관측수+저격수. 시계는 향후 활동/실제 시뮬레이션 tick으로만 전진.
- `overwatch/storage.js`: 새 주 저장/백업, 복원·가져오기·내보내기·충돌 감지. 기존 PMC 키는 읽기 전용.
- `overwatch/app.js`와 `overwatch/app.css`: 본부·인원·작전·장비·기록·저장 관리. 미구현 단계는 명시하고 실행 버튼을 제공하지 않는다.
- 후속: command/event queue, observer AI, world truth, HQ knowledge, transport FSM을 독립 모듈로 추가. 2D/3D는 HQ에 전달된 동일 frame을 읽는다. 시각화가 적 실제 좌표를 따로 조회하면 안 된다.

## 단계 및 완료 기준

1. **본부/저장**: 새 진입점, 독립 상태, 기존 원본 보존, 백업/가져오기/손상 복구, PC/모바일 검사. 구형 게임은 `legacy-pmc.html` 및 Git 이력으로 보존하며 새 앱에서 자동 실행하지 않는다.
2. **인원/편제**: 모집·계약·훈련·의료와 10명 상한, 주특기 1개/부특기 0~2개, 최대 3개 2인조, 사망 영구 보존. 실제 입출금/편성 검사.
3. **AI/무전/정보**: 명령 수신→복창→관측수 판단→내부 지시→행동→실제 사건 보고. 통신 단절/오래된 정보/관측수 행동 불능 대행 검사.
4. **전장**: 1/2/4배속·일시정지·긴급 정지, 실제 2~6개 개체와 독립 적 AI, 지형/기상, 동일 상태 2D/3D 및 성능 검사.
5. **계약/지원**: 기관별 목표·제약·제공 지원. 수송 출발/이동/착륙/하차/철수/탑승, 지원 없는 임의 출동 금지. 목표 완료와 철수/정산 분리.
6. **통합**: 실제 사격만 탄약 소비, 재장전·성장·해금, 중복 정산 방지, 진행 중 저장/복구·장기/모바일 검사.

## 저장 전환

기존 36명 편제나 진행 중 24명 작전을 새 10명/6명 제한에 맞춰 자르지 않는다. 기존 두 키의 원본 바이트는 수정/삭제하지 않는다. 새 진행은 `blackline_overwatch_v1`/`blackline_overwatch_v1_backup`에 별도로 저장한다. 기존 명부·작전·보고는 보관함에서 요약/원본 다운로드할 수 있다. 새 데이터를 덮어쓰는 가져오기/초기화는 사전 보관본을 확보하고 실패하면 이전 값으로 복구한다. 현재 단계가 이해할 수 없는 스키마는 거부하고 원본을 보존한다.

주 저장 손상 시 백업을 제시하며 자동 덮어쓰지 않는다. 둘 다 손상되면 저장 동작을 잠그고 원본 다운로드/복구만 허용한다. 저장 실패 시 메모리 상태도 성공으로 전진시키지 않는다. 다른 탭의 새 revision을 덮어쓰지 않는다.

## 검증

Node: 기존 회귀 전체 + 새 순수 코어·저장 단위 검사. 브라우저: 새/기존 JSON/압축 저장, PMC 원본 불변, 재접속·내보내기/가져오기, 손상/백업/초기화/저장 실패·다중 탭, PC/모바일 오버플로, 구형 자동 타이머 미실행. 1단계에는 실제 AI·작전·3D를 완료했다고 보고하지 않는다.
