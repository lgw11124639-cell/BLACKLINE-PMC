# 대원 이미지

프로젝트용으로 생성한 입체 대원의 8방향 렌더 이미지입니다. `pmc-directions.webp`는 1536×1024, 4열×2행이며 방향 순서는 동·남동·남·남서 / 서·북서·북·북동입니다. 이동 방향에 따라 해당 이미지를 선택하여 지도 좌표 위에 표시합니다. 실제 3D 메시나 스켈레탈 애니메이션은 아닙니다.


v2026.11.09.35에서 추가한 생성 이미지:

- `hostile-directions.webp`: 황갈색 복장 적대 인원 8방향, 4열×2행.
- `casualties.webp`: 부상·전투 불능·응급처치·들것 후송 8장면, 4열×2행. 비유혈 표현이며 캐릭터 상태에 맞는 셀을 표시합니다.
- `vehicles.webp`: 수송 차량 동/남 방향, 항공기 동/남 방향, 2열×2행. 지도 이동과 지원 이벤트의 좌표·방향에 맞춰 표시합니다.

모두 1536×1024 투명 WebP이며 원본 PNG는 생성 이미지 디렉터리에 유지합니다. 이미지는 정지 렌더이고, 이동·조준·발사·폭발은 실제 시뮬레이션 데이터에 따라 Canvas에서 합성합니다.
