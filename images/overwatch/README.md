# OVERWATCH 개별 캐릭터 자산

43개의 투명 WebP 파일. OpenAI 이미지 생성으로 제작한 가상의 성인 캐릭터이며 원본 PNG는 생성 작업 공간에 보존한다. 캐릭터를 한 장의 아틀라스로 자르지 않는다. manifest.json의 알파 경계와 크기는 sprites.js에도 포함되어 HTTP 없이 선택 로직을 검사할 수 있다.

저격수(헬멧·AXMC), 관측수(헬멧·HK416/관측경), 적 정규군/반군, 지원 아군, 민간인, 적 저격수(SVD)의 자세와 부상/사망 파일을 분리한다. 정상/부상/사망 판단은 이미지가 아닌 시뮬레이션 의학 상태가 결정한다. 경상 부상 자세는 전투 후에, 처치 완료·보행 가능한 경우 정상 자세로 돌아간다. 의식불명/전사는 즉시 별도 상태로 표시한다.

저격수 엎드림은 prone 관측 자산에 실제 사격 반동/화염을 결합한다. 적 저격수 이동은 SVD 서기 자산에 보행 보간을 사용한다. 좌우 반전은 가능하나 모든 방향의 별도 모델/스켈레탈 애니메이션은 아니다. 몸의 혈흔과 지면 혈흔은 실제 보고된 부상/명중으로 렌더러가 추가하며 사망 그림 자체로 의학적 판정을 하지 않는다.

런타임은 필요한 이미지만 읽어 최대 512px 텍스처를 16개까지 보유한다. 원본 파일/알파 경계는 변경하지 않는다. 전체 자산 다운로드는 약 7.6MB이며 실제 모바일 성능은 기기에 따라 별도 확인이 필요하다.

의료 회수 요원의 `medic-move`/`medic-aid`를 추가했다. 무기를 든 일반 전투병으로 표시하지 않으며 실제 치료 상태에서만 처치 자세를 사용한다. 의료 자산의 bounds는 작은 알파 노이즈를 제외한 불투명 윤곽을 기준으로 한다. 원본 PNG는 보존한다.
