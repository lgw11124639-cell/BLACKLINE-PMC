# BLACKLINE: OVERWATCH 전환 계획

범위: 사용자 개발 지시서의 1단계. 이 문서는 전체 게임 구현 완료를 의미하지 않는다.

## 분석 기준

최종 기준 커밋 `c5704a8` (원격 main, v2026.11.10.02). 초기 로컬 `470e338`에서 시작했으나 원격 100개 추가 커밋을 확인한 뒤 최신 기준으로 재배치했다. 추가된 17개 파일의 633행 삽입/74행 삭제를 그대로 보존한다. 정적 HTML/JavaScript 프로젝트이며 빌드 도구나 서버 데이터베이스가 없다. 진입점 `index.html`은 약 62KB의 UI·초기 상태·저장 코드와 다수의 전역 스크립트를 실행한다. 최신 변경에는 의료후송 잔여 대기 정리, 지상 복귀와 헬기 도착 조건 분리, 복귀 정체 복구, 비동기 저장 보강, 60~96명 적 중대·지원전력·접촉 확률 변경과 UI 보정이 포함된다. 적 중대의 전체 아군 위치 참조와 기존 대규모 전력 정책은 OVERWATCH의 제한 정보·6명 출격 규칙과 맞지 않으므로 그대로 이식하지 않는다. 기존 상태는 `blackline_pmc_v1`, `blackline_pmc_v1_backup`에 저장한다. `save-codec.js`는 기존 JSON 및 BLZ1 압축 저장을 모두 읽는다. `save-scheduler.js`/`save-worker.js`는 기존 키에 직접 기록하므로 새 앱에서는 실행하지 않는다.

## 새 경계

- `overwatch/core.js`: DOM 없는 상태 스키마·제약·유효성 검사. 최대 10명, 출격 2~6명, ALPHA/BRAVO/CHARLIE 각 관측수+저격수. 시계는 향후 활동/실제 시뮬레이션 tick으로만 전진.
- `overwatch/storage.js`: 새 주 저장/백업, 복원·가져오기·내보내기·충돌 감지. 기존 PMC 키는 읽기 전용.
- `overwatch/app.js`와 `overwatch/app.css`: 본부·인원·작전·장비·기록·저장 관리. 미구현 단계는 명시하고 실행 버튼을 제공하지 않는다.
- 후속: command/event queue, observer AI, world truth, HQ knowledge, transport FSM을 독립 모듈로 추가. 2D/3D는 HQ에 전달된 동일 frame을 읽는다. 시각화가 적 실제 좌표를 따로 조회하면 안 된다.

## 단계 및 완료 기준

1. **본부/저장**: 새 진입점, 독립 상태, 기존 원본 보존, 백업/가져오기/손상 복구, PC/모바일 검사. 구형 게임은 `legacy-pmc.html` 및 Git 이력으로 보존하며 새 앱에서 자동 실행하지 않는다.
2. **인원/편제**: 모집·계약·훈련·의료와 10명 상한, 주특기 1개/부특기 0~2개, 최대 3개 2인조, 사망 영구 보존. 실제 입출금/편성 검사.
3. **AI/무전/정보**: 명령 수신→복창→관측수 판단→내부 지시→행동→실제 사건 보고. 통신 단절/오래된 정보/관측수 행동 불능 대행 검사.
4. **전장**: 1/2/4배속·일시정지·긴급 정지, 실제 2~6개 개체와 독립 적 AI, 지형/기상, 동일 상태 2D/3D 및 성능 검사.
5. **계약/지원**: 기관별 목표·제약·제공 지원. 수송 출발/이동/착륙/하차/철수/탑승, 지원 없는 임의 출동 금지. 목표 완료와 철수/정산 분리.
6. **통합**: 실제 사격만 탄약 소비, 재장전·성장·해금, 중복 정산 방지, 진행 중 저장/복구·장기/모바일 검사.

## 저장 전환

기존 36명 편제나 진행 중 24명 작전을 새 10명/6명 제한에 맞춰 자르지 않는다. 기존 두 키의 원본 바이트는 수정/삭제하지 않는다. 새 진행은 `blackline_overwatch_v1`/`blackline_overwatch_v1_backup`에 별도로 저장한다. 기존 명부·작전·보고는 보관함에서 요약/원본 다운로드할 수 있다. 새 데이터를 덮어쓰는 가져오기/초기화는 사전 보관본을 확보하고 실패하면 이전 값으로 복구한다. 현재 단계가 이해할 수 없는 스키마는 거부하고 원본을 보존한다.

주 저장 손상 시 백업을 제시하며 자동 덮어쓰지 않는다. 둘 다 손상되면 저장 동작을 잠그고 원본 다운로드/복구만 허용한다. 저장 실패 시 메모리 상태도 성공으로 전진시키지 않는다. 다른 탭의 새 revision을 덮어쓰지 않는다.

## 2단계 구현 범위와 정책

대원 모집·계약·편성·본부 활동을 실제 저장 상태에 연결한다. 신규/1단계 저장은 schema 2로 전환하며 변환 전 주 저장과 백업을 별도 보관한다. 1단계 저장의 ID·설정·기록·명부는 유지한다. 초기 운영자금 1억원은 캠페인당 한 번만 장부에 기록한다.

- 주특기 관측수/저격수, 부특기 0~2개. 신입·경력·베테랑·전문가 후보는 경력/능력/일급을 공개하고, 30/90일 기간 급여를 선지급한다. 계약금 중복 지급·예산 초과·정원 초과를 거부한다.
- 현직 10명과 전사/퇴사/은퇴 명부를 분리한다. 사망/부상은 임의 발생시키지 않는다. 실제 사건을 인수하는 검증/중복 방지 핸들러와 의료 상태를 구현하며 현재 UI에서 전사·총상을 만들어내는 버튼은 제공하지 않는다.
- ALPHA/BRAVO/CHARLIE에 관측수 1명+저격수 1명. 중복/부상/계약 만료/훈련 중 인원 편성 금지. 조 단위 편성만 지원하며 아직 출격이나 AI 명령 기능은 아니다.
- 본부 활동은 개인 훈련/휴식/외부 협력 진료/재활/2인 공동 훈련. 활동을 배정한 뒤 다음 활동 완료까지 시간을 진행한다. 계약 시간과 모든 동시 활동이 함께 전진하고, 재접속/실제 벽시계 경과만으로 진행시키지 않는다.
- 활동 비용은 착수 때만 지출한다. 종료 사건과 능력/피로/스트레스/치료/팀워크 변화는 실제 활동 경과에 따라 한 번만 적용한다. 진행 중 저장을 복구해도 기한을 다시 계산하지 않는다.
- 기존 상처와 후유증은 보존하고, 진료 종료까지 부상 인원의 편성을 막는다. 중상 후유증은 실제 부위 기록에서만 산출한다. 출처가 없는 이전 상처는 부위를 지어내지 않고 미상 기록으로 보존한다.
- 지휘 AI·전투·탄약·3D·기관 계약 수송은 후속 단계다. 부특기 데이터의 AI 행동 연결도 3단계에서 구현한다.

## 관측수 교전·회피 권한과 명령 UI 통합 · v2026.11.15.09

지도 아래 조 선택·엄호/정찰/경계/전체 철수로 임무 명령을 통합하고 중복 상세 명령 폼 및 교전 방침 선택창을 제거했다. 주기 위치 메시지는 숨기되 내부 상태 수신을 유지한다. 선택 관심 구역은 지도에서 지정/해제할 수 있다.

앱에서 새 작전과 기존 진행 저장에 관측수 자율 권한을 활성화한다. 정찰/감시/경계는 선제 사격을 보류하고 가까운 실제 관측 위협에는 통행 가능한 엄폐·원거리 우회 경로를 계획한다. 철수 명령의 경로를 임의 우회 명령으로 대체하지 않는다. 엄호 중에는 실제 식별 접촉과 유효 사거리·가시선·정지 조건에서만 사격을 허용한다. 관측된 민간인/미식별/아군의 근접 또는 사격선 위험은 사격을 막으며 조원의 최근 실제 피격 위협은 자위 대응 근거로 공유한다. 실제 발사 직전 물리 사격선·탄약 검사도 유지한다. 판단 변화 보고는 실제 접촉과 관측 시각에 연결하고 판단/경로를 저장한다. 개발용 직접 엔진 시나리오의 수동 ROE API는 호환성을 위해 남겼으며 앱 UI에서는 사용하지 않는다.

검증: 기존 사살·시야·사거리·부상/복귀/저장 회귀 검사에 은밀 우회 거리 증가와 실제 경로 생성, 구형 사격금지 설정과 독립적인 엄호 판단, 민간인 위험 시 보류 및 판단 상태 복원을 추가했다. 브라우저에서 단일 명령 UI와 교전 선택창 제거, 조 명령 실행, 재접속 연속 진행을 확인한다.

## 가로형 관제실·지휘 편성 및 피격 피드백 · v2026.11.15.10

본부는 인원/저격조 편성과 작전 승인에 집중하고, 실제 소속 대원을 작전통제관과 훈련 교관에 배정할 수 있다. 본부 담당자도 10명 정원에 포함하며 현장 저격조/다른 활동/다른 직책과 중복하지 않는다. 해약·만료 시 직책을 해제한다. 위임한 새 실전 출격에는 가용 통제관이 필요하고 모의 훈련에는 교관을 배정한다. 이미 진행 중인 구형 저장은 중단하거나 임의로 대원을 추가하지 않는다. 본부에서 담당자를 배정한 뒤 위임할 수 있으며 미편성 상태에는 직접 명령을 남긴다.

실제 지휘 계통은 본부 승인 → 작전통제관 → 조 관측수 → 저격수다. 통제관이 계약의 공개된 지역과 전달된 접촉/조원 상태로 정찰 구역을 분담하고 엄호, 지원 및 철수를 지시한다. 명령·복창·보고에 담당자의 실제 ID/이름/직책을 기록한다. 통제관의 판단 주기는 실제 판단 능력에 영향을 받는다. 도보 투입 경로를 완료하기 전에 현장 정찰로 덮어쓰지 않는다. 알려진 중상/귀환으로 현장 운용 인원이 부족하거나 전체 보고가 끊기면 회수·수색을 요청한다. 구역 분담 정찰을 실제로 소진해도 식별에 실패하면 성공을 꾸미지 않고 철수를 결정한다. 판단/명령/진행 구역을 저장하며 수동 통제로 되돌려도 기존 지휘 기록은 보존한다.

관측수는 이동 시 두 명이 동시에 무방비로 진행하지 않도록 교대 엄호 이동을 사용한다. 정지한 조원은 실제 광학 관측을 수행하고 이동한 조원이 구간을 확보하면 역할을 교대한다. 부상한 동료를 버리고 기존 경로를 계속 진행하지 않는다. 두 센서의 관측을 합칠 때 관측수의 낮은 식별 거리로 저격수의 실제 장거리 식별 결과가 깎이던 오류를 수정했다. 탐지·식별·사거리 및 시야/사격선 검사는 유지한다.

본부의 직접 UAV·의료 회수·보급 요청은 유지한다. 통제관 자동 지원은 별도로 켜고 끌 수 있으며 계약 제공 횟수와 이미 출동한 자원을 확인한다. UAV는 실제 이동·관측·복귀를 하며 시야 안의 적만 지연 보고한다. 본부에서 관심 구역을 지정하거나 기존 기체를 재배치할 수 있고 UAV를 추적 관전할 수 있다. 재배치는 새 출동 횟수나 체공 시간을 만들어내지 않는다. UAV의 반복 위치 자료는 내부 정보 갱신으로 전달하되 무전 피드에는 중복하지 않는다. 관측 표적의 사망/행동불능 전환도 실제 관측에 연결한다.

가로형 UI는 지도 중심의 관제실과 독립적으로 전환하는 무전/대원/본부·지원 패널을 사용한다. 중복된 명령 폼과 교전 방침 선택창을 제거하고 위임 시 개별 조 임무 버튼을 숨긴다. 본부·인원·작전 승인·기록 화면도 같은 게임 셸을 쓴다. 장비 탭은 실제 수신한 지급/탄약/내구·방호 상태를 보여준다. 667×375, 844×390, 낮은 높이 844×320, 1440×900에서 레이아웃을 검증한다. 세로 화면에는 회전 안내를 제공하고 사용 가능한 브라우저에서는 전체화면/가로 방향 잠금을 요청한다. iOS에서 지원하지 않는 방향 잠금을 강제한 것으로 보고하지 않는다. 2D 전술도와 입체 지도/기존 3D 화면은 같은 상태를 사용한다.

피격은 고위력탄이라는 이유만으로 모든 머리 접촉을 즉사로 처리하지 않는다. 중심 관통과 스침, 방탄판 충격 및 실제 방호 손상을 구분한다. 치명적 머리 관통은 여전히 사망할 수 있다. 중증 몸통 피격과 반복 몸통 관통은 행동 불능/출혈로 이어지고 구조 기회를 가진다. 출혈은 실제 미처치 상처에서 누적되며 부상자를 자동 소생시키지 않는다. 공격받으면서도 완성된 조준을 그대로 재사용하던 문제를 수정하고 실제 제압/이동 표적 추적을 명중 분산에 반영한다. 보통 보행 표적이 계속 조준을 초기화해 불사신이 되는 문제도 막는다. 가벼운 부상에 적 사격이 이어져도 즉시 처치에 매달려 대응하지 못하던 경로를 수정했다.

미식별 적의 사격이라도 아군 가까이에 들어온 실제 탄착/피격은 효과·소리로 전달한다. 이때 적 ID와 발사 원점은 공개하지 않는다. 최초 사용자 조작에서 오디오를 활성화할 수 있으며 음소거 의도는 유지한다. 의식불명 대원에게 사망 이미지를 사용하지 않도록 별도 한국인 저격수/관측수 이미지 두 장을 추가했다. 지도에 이름·역할을 표시하고 최소 가독 크기와 라벨 겹침 방지를 적용한다. 실제 본부로 돌아온 차량/헬기/UAV는 상태·기록을 보존하면서 지도에서 숨긴다. 기존 3D 장면의 남은 기체 메시와 회전도 중단한다.

## 2026.11.15.12 — 관제 분리와 스크롤 복구

## 2026.11.16.01 — 기관 보병, 옥상 진지, 시각 식별과 인계 충돌

기관의 무장 구출·경호·경계 인력을 관측수로 투영하던 오류를 수정했다. 기관 인력은 infantry/기관 보병·구출 보병·경호 보병으로 구분하고 기존 allied 자세별 아트를 사용한다. 의무 후송 인력은 medic으로 유지한다. 시가지 4종의 건물에 접근 가능한 옥상 출입 경로와 평면 옥상 영역을 연결했다. 관측수는 지상·엄폐·고지·옥상 가장자리의 실제 시야와 접근 가능성, 알려진 위협 및 지원 아군을 비교해 진지를 선정한다. 다른 저격조가 점유한 옥상은 피한다. 지상 접근, 높이에 따른 계단 이동 시간, 옥상 이동, 하강을 거치며 실제 고도를 LOS/관측에 사용한다. 계단 중 격발하지 않는다. 입체 일러스트에서는 실제 고도를 비스듬한 지도 위로 투영하고 3D에서는 고도로 배치한다. 내부 방별 전투나 상세 계단 메시를 구현했다는 뜻은 아니다.

옥상 부상자의 보고를 받으면 착륙 지점은 옥상 출입구 인근 지상으로 잡는다. 의료 승무원이 계단으로 접근·처치·운반·하강한 뒤 실제 탑승시킨다. 다른 층에서 처치하거나 공중에서 탑승시키지 않는다. 지상 경로에는 직사각형 장애물의 정확한 선분 교차를 추가해 샘플 사이의 모서리로 경로를 통과시킨 뒤 이동 중 막히던 문제도 수정했다.

적 AI의 시각 확인은 거리/방향/LOS만 만족하면 즉시 정확한 기억을 얻던 구조에서 누적 식별로 변경했다. 자세, 저격수의 정지 은폐, 실제 이동, 그림자/엄폐, 거리, 기상과 실제 격발 흔적을 반영한다. 가까운 인원은 빠르게 보이고 소음기 장착 후에도 격발은 단서를 높인다. 소리만으로 정확한 표적 기억을 생성하지 않으며, 시야를 잃으면 마지막 확인 위치가 갱신되지 않는다. 기관 보병에도 같은 누적 식별 함수를 사용한다. 확률 주사위로 발각 여부를 정하지 않고 실제 상태에 따른 누적값을 저장한다. 이는 게임 모델이며 현실 군사 관측 성능의 검증값이 아니다.

## 2026.11.16.02 — 외곽 저격 엄호와 관측 기반 보병 진출

새 시가지 실전에는 원본 240×160m 훈련 지도의 별도 1,200×800m 작전 변형을 사용한다. 무기 사거리(AXMC 1,100m / HK416 450m / AKM 350m / SVD 750m)는 실제 좌표 미터 기준이며 확대나 캐릭터 표시 크기로 달라지지 않는다. 일러스트 지도에 현재 배율의 거리 눈금을 표시한다. 원본 지도와 이미 출격한 저장의 위치/부상/배치는 유지한다. 아직 출격하지 않은 구형 시가지 계약만 출격 시 광역 변형으로 연결하며, 이 변경은 인사·돈·계약 보수를 초기화하지 않는다. 지형 그림은 기존 에셋을 재사용한다.

작전통제관은 ALPHA에 외곽 고정 관측·대저격, BRAVO에 기관 진출로/구출 엄호, CHARLIE에 측후방·철수로 경계를 배정한다. 1개 조일 때는 지역 저격 엄호를 맡는다. 각 관측수는 다른 조의 진지와 이동 경로를 고려하며, 선행 조가 실제 진지에 도착해 엄호하는 동안 후속 조가 전개한다. 사수는 선행 이동, 조 내부에서는 구간별 엄호 교대를 수행한다. 정찰 완료 뒤 단순 엄호 전환은 진지를 유지하고 관측 방향을 바꾼다. 신규 기관 진출로가 사각일 때는 한 조만 이동시킨다. 실제 표적 선택도 대저격·진출로·철수로 임무에 따라 우선순위를 달리한다.

기관 보병은 저격조가 외곽 진지를 확보하고 보고하기 전에는 대기한다. 본부가 받은 조 상태·시야·현재 접촉을 기준으로 다음 35m 이내 구간을 승인하며, 감시 방향 전환/진지 이동 중에는 보병도 정지한다. 알려진 위험 구간은 감시 가능한 다른 경로와 실제 남은 경로 길이를 비교한다. 비인가 대기 중 먼 적에게 먼저 사격하지 않으며, 실제 피격에는 자위 행동을 한다. 승인 상태·근거·준비 조·경유점은 저장하고 지원 패널에서 표시한다. 이 통제는 무적 처리나 적 위치 자동 공개가 아니다.

적 저격수의 장거리 조준경 시야는 좁은 전방으로 한정하고, 주변 육안 시야는 별도로 계산한다. 은밀 정찰 중 아군은 단순 공유 접촉 때문에 몸을 일으키거나 발사하지 않는다. 확인된 표적은 사격 승인 전에도 실제로 조준하며, 승인 전에는 탄약/탄피/총성/피해를 만들지 않는다. 표적 전환에도 안정성을 주어 조준을 무한히 다시 시작하지 않도록 했다.

진행 정체 수정: 대기 중인 다른 조를 실제로 우회할 수 있게 하고 새 명령에 이전 막힘 시간을 넘기지 않는다. 옥상 우회점의 층 정보를 유지하며 계단 앞 경유점을 임의로 생략하지 않는다. 다른 층의 인원은 지상 경로를 막지 않는다. 지상 차량의 회수점에서 옥상 태그를 제거하고 계단 입구로 접근한다. 보병과 보호 대상이 벌어지면 실제 재합류하며, 구출·호송 조장 행동 불능 시 근처 가용 기관 보병이 지휘를 인계한다. 가용 보병이 전멸하면 수행 불가를 보고하여 끝없는 목표 대기를 막는다. 시가지 LOS는 정확한 장애물 교차 계산으로 넓은 지도의 반복 샘플 비용을 줄였다.

검증: Node 188개 통과. 신규 6개 검사는 1.2km 지도/기존 지도 보존, 실제 6명 외곽 전개·초기 보병 대기·조별 임무, 비발사 조준 탄약 보존, 적 조준경 방향별 식별, 층별 통행·실제 하강, 기관 지휘 인계/전멸 판단을 포함한다. 기존 5종 자동 작전은 실제 목표 달성과 전원 물리 복귀를 유지하며, 광역 지도 이동 거리를 반영해 검사 시간 예산을 늘렸다. 실제 적 사격을 켠 추천 편제 추가 실행에서는 VIP/보급 임무가 목표를 달성하고 철수했으며 구출 임무는 기관 보병 손실로 실패 후 저격조 6명 철수했다. 성공을 강제하거나 피해를 면제하지 않는다. 브라우저 8개 시나리오 통과: 기관 아트/옥상/관측통제 패널, 회전 전체화면 스크롤, 관제 분리, 실제 승인·UAV, 총성, 연속 진행, 구버전 구조/정산, 복귀 기체 제거. 사거리/관측/명중은 게임 내 모델이다. 기존 진행 저장은 초기화하지 않으며, 새 구역 크기는 다음 출격부터 적용된다.

## 2026.11.16.03 — 실전 경로 복구, 지역 선택, PC 관제, 적 접근 AI

사용자가 보고한 `훈련 대원·경로가 잘못되었습니다` 오류를 구형 실전 수송 저장으로 재현했다. 이전 코드에서 지상 차량에 옥상 경로가 남아 있으면 탑승자는 차량 이동 후에도 roofId를 갖고 있어 다른 위치에서 검증에 실패한다. 동일 회귀 검사를 이전 .02 코드에 실행하면 이 정확한 오류가 발생한다. 업데이트는 잘못된 차량 경로를 실제 도로/옥상 출입구 경로로 복구하고 사건을 남긴다. 탑승 중 대원의 독립 이동/계단/옥상 상태도 해제한다. 건강·인원·보수·기존 작전은 초기화하지 않는다. 검증을 완화하지 않으며, 다른 대원 경로 오류는 이름과 위치/층/경유점 구분을 표시해 원인을 추적할 수 있게 했다. 실제 사용자 저장 파일을 직접 확보한 것은 아니므로 모든 저장 오류가 동일 원인이라고 단정하지 않는다.

접수된 의뢰 카드에서 출격 전 작전 지역을 선택할 수 있다. 시가지 4종(구도심·업무지구·항만·시장)을 같은 임무 유형에도 사용하며, 정찰은 능선도 선택한다. 선택하면 실제 mapId, 투입/철수 지점, 관측 구역과 지역 제목을 함께 저장한다. 수락/출격 후에는 전장 위치를 바꾸지 않는다. 새 의뢰 묶음은 지역을 순환하고 관측 목표도 변경한다. 기존 그림과 지형을 재사용하며 신규 지도 아트를 생성했다고 주장하지 않는다.

PC(가로 1366px 이상, 높이 650px 이상)는 넓은 지도와 390~460px 관제 패널을 사용한다. 무전은 상시 표시하고 그 아래 대원/지원 패널을 별도로 스크롤한다. 1440/1920 화면의 글자·버튼 크기를 늘리고, PC에서 입체 지도를 처음 열면 전장 전체를 표시한다. 휴대폰의 패널 전환과 회전 스크롤을 유지한다.

새 실전 적은 집결 지점에 실제 개체로 생성되어 작전지로 이동한다. 조별 출발 시차가 있고 미발견 적은 HQ 지도에 공개하지 않는다. 정규군은 2인조로 이동/엄호를 18초 구간마다 교대하며, 접촉 후 상대 조원이 표적을 조준 중일 때 다른 인원이 실제 경로로 측면 이동을 시도한다. 반군은 별도 엄호 교대 없이 느슨하게 진출하고 접촉/총성에 개별 대응한다. 양측 모두 실제 관측·LOS·탄약·부상에 따른 기존 전투를 사용하고, 이미 진행 중인 구형 작전의 적 배치를 다시 생성하지 않는다. 적의 이동 애니메이션도 실제 이동 상태를 반영한다.

검증: Node 193개 통과. 신규 검사는 의뢰 지역/목표 순환, 실제 지형 선택과 저장/출격 후 변경 차단, 구형 옥상 차량/탑승자 복구, 적 집결·접근, 정규군 엄호 교대와 반군 이동 차이를 포함한다. 브라우저 9개 시나리오(새 PC 관제/지역 선택, 기존 관제 레이아웃, 전체화면/회전 스크롤, 실전 승인/UAV, 기관 아트/옥상, 구형 실전 회수, 오디오, 연속 진행, 복귀 기체 제거)를 통과했으며 PC 기본 전체 시야 변경 후 PC 관제를 재검사해 통과했다. 추가 8개 실전/훈련과 구형 소형 항만 작전 12개 시드에서 저장 검증을 수행했다. 일부 구형 작전은 검사 시간 내 복귀가 완료되지 않았으므로 이 추가 검사 결과를 전부 성공/복귀로 해석하지 않는다.

## 2026.11.16.04 — 본부 동선, 선택 출격, 인원 가독성

본부의 고정 높이 카드별 스크롤을 제거하고 main 하나에서 스크롤한다. 출격 준비/편성된 조 명단을 먼저 배치하고 지휘 편성을 나란히 둔다. 좁거나 낮은 화면에서는 한 열로 전환한다. 큰 장식 지도는 제거하고 지원 인력 채용/계약 관리는 접어서 필요할 때 연다. 채용/배정으로 화면이 갱신되어도 접기 상태를 유지한다. 진행 중인 모의 훈련은 본부에서 실전 관제로 보내지 않고 훈련 관제로 연결한다.

수락한 계약에서 ALPHA/BRAVO/CHARLIE를 개별 선택하며 투입 조 수/인원/소모품 예치가 즉시 바뀐다. 선택은 계약에 저장한다. 실전 엔진은 선택한 조의 관측수/저격수만 실제 개체로 생성하며, 본부 편제/미투입 대원은 그대로 둔다. 사격/부상/수송/보수 정산은 실제 투입 명부를 사용한다. 미선택 조의 피로/부상은 선택된 건강한 조의 준비 검사를 방해하지 않는다. 계약 최소 인원, 최대 3개 조/6명, 출격 후 선택 변경 금지를 유지한다. 기존 선택 필드가 없는 저장은 기존 전체 편제로 출격하고 모의 훈련은 원래 편제 전체를 사용한다.

입체 지도에서 공통 최소 표시 배율을 PC 12/모바일 8로 조정해 이전 4보다 인원을 크게 표시한다. 저격수/관측수/적/기관 보병/민간인에 같은 표시 배율을 적용한다. 넓은 시야에서는 이름을 간결히 표시해 역할 문구 중첩을 줄이고, 실제 미터 좌표·관측·사거리·명중 판정은 바꾸지 않는다.

검증: 전체 Node 테스트 197개 통과. 신규 선택 출격 검사는 BRAVO 단독 출격 시 실제 2명·본부 6명/3개 편제 보존·예치금 1/3·미투입 피로 대원 분리, 0개/계약 최소 미달/중복 조 거부, 구형 계약과 모의 훈련 편제 유지, 1개 조의 실제 하차 후 정찰 개시를 확인한다. 이 과정에서 탑승 중이라는 지연 보고 때문에 하차 직후 인원 부족으로 오인해 즉시 철수하던 문제를 발견했다. 통제관이 현장 인계 보고를 기다리게 수정하고 회귀 검사를 추가했다. 브라우저에서는 본부 단일 스크롤·채용/배정·접기 유지, 실제 1개 조 선택/저장/출격/확대된 공통 표시 크기, 작전 승인/UAV, 기존 관제 레이아웃, 전체화면 회전 스크롤, PC 무전/대원 병렬 표시를 검증했다. 본부 UI 변경은 저장 초기화를 요구하지 않는다.

## 2026.11.16.05 — 실제 청취 음향, 기본 진행 속도, 확대, 임무 정체 대응

소리는 기존에 시각 확인/근접 탄착 사건만 전달받고 있었다. 실제 적 격발을 청취했지만 사수/탄착이 안 보이면 보고만 생성되고 소리는 누락되는 경우를 재현했다. 청취 거리 내 실제 사격은 audio-only 효과를 전달한다. 미확인 발사원은 위치·ID·무기/진영을 공개하지 않으며 청취자 위치와 대략적인 거리 구간만 사용한다. 이 효과는 양쪽 렌더러의 탄도/격발 섬광에서 제외한다. 같은 사격을 한 조가 소리로만 알고 다른 조가 확인했다면 더 강한 실제 관측 증거로 갱신한다. 동일 사건을 중복 재생하지 않는다.

아군 AXMC/HK416의 소음기 음색, AKM, SVD의 음색·재생률·필터를 구분한다. AXMC/SVD는 같은 원본 계열 녹음이지만 재생률/소음기 필터가 다르며, HK416/AKM은 다른 원본 계열을 사용한다. 확인된 아군 지원/적 사격 보고 문구도 구분한다. 미확인 총성은 먼 저역 총성으로 재생하며 적이라고 단정하지 않는다. 빨라진 프레임에서도 최근 5초 이내 수신 효과를 재생해 누락을 줄인다. 기존 오디오 활성화/음량/백그라운드 중지/원본 녹음 라이선스를 유지한다.

실제 게임 런타임의 기본 진행을 4로 설정하여 1×가 종전 4×가 된다. 표시 1/2/4는 실제 4/8/16 시뮬레이션 초/초다. 내부는 여전히 1초 고정 단계이며 배속으로 명중/사거리/판단 규칙이 달라지지 않는다. 화면 갱신은 펌프당 한 번, 자동 저장 단계 간격도 기본 속도에 맞춰 묶어 불필요한 반복을 줄인다. 숨겨진 탭의 경과 시간을 몰아서 진행하지 않는다. 인원 표시도 지도 확대율을 따라 커지고, 근접 최대 표시만 제한한다. 판정 좌표/미터 사거리는 그대로다.

기관 보병/구출조의 미처치 부상은 기존 경로에서 즉시 return되어 실제 처치 없이 정지할 수 있었다. 안전할 때 자신의 의료품 또는 같은 층 가까운 기관 보병의 의료품으로 실제 처치를 시작하게 한다. 의료품이 없는 행동 불능 조장은 가용 보병에게 지휘를 인계한다. 작전통제관은 기관의 실제 수신 위치, 남은 목표 경로, 저격조의 새 경로·진지 진전으로 정체를 판단한다. 첫 300초간 유의미한 진전이 없으면 엄호 진지/진출로를 한 번 재검토하고, 재검토 후에도 마지막 진전으로부터 600초간 같은 지역을 반복하면 수행 불가를 보고하고 실제 철수·회수를 요청한다. 정상적인 새 이동 경로/느린 옥상 접근은 진전으로 처리하며, 단순 작전 총 경과시간 제한이나 자동 목표 달성/자동 복귀가 아니다. 진행 중인 구형 저장도 이 평가를 적용한다.
